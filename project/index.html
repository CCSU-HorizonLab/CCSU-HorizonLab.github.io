Chrono_Trace

Python 开源公开

源码可见、限非商业使用的本地桌面工具，用于分析已获授权的微信聊天数据，并生成隐私优先的沟通洞察。

Key Features

核心亮点与特性

聚焦真实场景需求，兼顾性能、隐私与易用性。

隐私优先

所有聊天数据分析均在本地完全离线进行，不上传任何云端服务器，保障隐私安全。

深度沟通洞察

自动提取聊天频次、高频词云、情绪趋势与对话节律，生成多维度可视化图表。

开箱即用桌面端

提供极简桌面图形界面，无需复杂环境配置，一键导入并开启洞察报告。

Get Started

快速开始与使用指南

简单的几步，即可在本地运行该项目。

Terminal 
# 克隆项目仓库
git clone https://github.com/CCSU-HorizonLab/Chrono_Trace.git
cd Chrono_Trace

# 安装依赖并启动
pip install -r requirements.txt
python main.py
